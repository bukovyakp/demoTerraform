# Principles

> Як обираємо між варіантами, що проходять constraints. Порядок = пріоритет.

1. **Managed > self-hosted**, якщо різниця у вартості < TODO% — людські години дорожчі.
2. **Простота > гнучкість**: не беремо інструмент "на виріст" без вимірюваної потреби.
3. **Все в IaC**: варіант без нормальної підтримки в Terraform штрафується.
4. **Шлях відходу**: для критичних даних — стандартні протоколи/формати.
5. **Least privilege і шифрування за замовчуванням.**
