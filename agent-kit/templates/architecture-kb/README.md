# Architecture KB

Єдина база архітектурних знань для всіх репозиторіїв. Читається скілами плагіна `arch-research`.

- `constraints.md` — жорсткі обмеження (порушення = варіант відкидається)
- `principles.md` — як обираємо, коли обмеження дозволяють кілька варіантів
- `landscape.md` — що є зараз
- `research/<YYYY-MM>-<topic>/` — дослідження (brief, options, comparison)
- `adr/` — прийняті рішення
