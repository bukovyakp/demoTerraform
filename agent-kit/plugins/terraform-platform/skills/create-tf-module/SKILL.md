# Create Terraform module

## 0. Контекст
Прочитай `AGENTS.md` репозиторію: секції Layout, Dependencies, Versions. Якщо їх немає — зупинись і запропонуй `/terraform-platform:tf-onboard-repo`.

## 1. Вхідні дані (спитай, якщо бракує)
- Шлях `<stage>/<service>/<name>`
- Що створюємо: ресурси, ключові параметри
- Від яких існуючих модулів залежить (VPC, SG, кластер, ALB...)
- Чи є ADR/рішення щодо цього сервісу (див. Architecture в AGENTS.md)

## 2. Кроки
1. Знайди найближчий за змістом модуль; якщо немає — еталонний з AGENTS.md. Відтвори його структуру файлів і нумерацію.
2. Залежності підключай **тим самим механізмом**, що й еталон (напр. додай ключ у `terraform_remote_state` for_each), а не новим.
3. Змінні — у `96-variables.tf` з `description` і `type`; без дефолтів для середовищних значень.
4. Виходи, потрібні іншим модулям, — у `99-outputs.tf` з `description`.
5. Теги — через спільний механізм репо (default_tags / locals), не хардкодь.
6. Не пиши `provider`/`backend` вручну, якщо їх генерує terragrunt (`generate`).

## 3. Перевірка
Запусти `/terraform-platform:tf-validate` для нової папки. Виправ усе до того, як звітувати.

## 4. Звіт
Список створених файлів, нові змінні (які треба задати в середовищі), нові outputs. Запропонуй наступний крок: `create-tf-environment`.
